# 测试说明

## 自动化测试

运行：

```bash
pytest -q
```

覆盖范围：

- 同比增长计算；
- 零分母安全处理；
- 历史分位计算；
- 最大回撤计算；
- 样本不足时不生成波动率；
- 演示数据完整主链路；
- 诊断引用只来自已有证据；
- 净利润缺失时生成未知结论；
- 现金利润比无法计算时不崩溃。

## 人工验收清单

| 场景 | 操作 | 期望结果 |
|---|---|---|
| 正常主链路 | 使用内置演示数据诊断 | 页面展示指标、四类发现、证据详情和图表 |
| 数据标识 | 使用内置演示数据 | 页面顶部持续显示合成数据警告 |
| JSON 缺字段 | 上传缺少 `valuation` 的文件 | 页面说明缺少字段，不生成正常诊断 |
| 字段为空 | 将本期 `net_profit` 设为 `null` | 利润增速标记为未知，现金利润比不可计算 |
| 零分母 | 将本期 `net_profit` 设为 `0` | 不出现除零错误，不生成虚假比率 |
| 接口超时 | 让数据桥响应超过 25 秒 | 页面提示金融数据接口超时 |
| 接口非 JSON | 数据桥返回 HTML | 页面提示未返回有效 JSON |
| LLM 未配置 | 删除 `LLM_API_KEY` | 使用确定性归纳并明确标记 |
| LLM 失败 | 配置不可访问的 LLM 地址 | 自动降级，不影响指标和证据展示 |
| LLM 伪造引用 | 模型返回不存在的证据 ID | 输出被拒绝并回退确定性归纳 |
| 合规表达 | 检查页面所有结论 | 不出现确定性预测、收益承诺或直接买卖建议 |

## 真实数据上线前检查

1. 确认财务期间可比，不能把季度值和年度值直接同比。
2. 确认所有货币字段单位一致。
3. 确认百分比使用 `25` 表示 `25%`。
4. 披露行情复权方式和价格区间。
5. 披露估值历史分位的样本时间和频率。
6. 随机抽取至少三项指标，与数据源原文或控制台结果核对。
7. 断开一个数据源，确认页面不会静默生成“正常”结论。
8. 在全新浏览器中检查部署 URL 和交互。
